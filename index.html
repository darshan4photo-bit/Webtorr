    Built-in addon

    Use Streamtor inside Stremio

    Streamtor speaks the Stremio addon protocol. Install it once and this server's library shows up as a catalog inside Stremio — every file streams straight from your server, with on-the-fly conversion for MKV, HEVC and friends.

    protects your addon URL — same code as the site
    Install in Stremio
    1. Install Stremio on desktop or mobile from stremio.com.
    2. Add the addon: Addons → Community Addons → paste the manifest URL — or press “Install in Stremio” above on the device that has Stremio installed.
    3. Open Discover and pick the Streamtor Library board: every torrent added on this server shows up, ready to stream. Episode packs appear as series.

    Streams are served by this server over HTTP — the same engine powers the web player, including compatibility mode and subtitles.

    The Stremio addon needs the Node server engine (server.js). On a static host only the in-browser WebTorrent engine runs, so there is no addon to install. Deploy Streamtor on Render/VPS to enable it.

    How it works

    🧲

    1. Add a torrent

    Paste a magnet link, info-hash or .torrent URL — or drop the file. The server fetches metadata from peers and lists everything inside.

    ⚡

    2. Stream as it downloads

    Pieces are fetched in playback order and served over HTTP range requests. Browsers-native codecs stream-copy; MKV, HEVC, DivX and WMV are converted to H.264/AAC on the fly.

    🧩

    3. Watch anywhere — even Stremio

    The same library is exposed as a Stremio addon: a catalog of everything on the server, with per-episode streams. Install it once with the manifest URL.

    FAQ

    How does the Stremio addon work?

    Streamtor implements the Stremio addon protocol: a manifest.json plus catalog, meta and stream endpoints under /stremio/<code>/. The catalog lists the torrents currently on the server (movies and episode packs as series); opening one lists every playable file as a stream that Stremio plays from your server's URL. Add a torrent on the website and it appears in Stremio's Discover board.

    Who can use the addon?

    The addon URL contains your server's access code, so on a server with ACCESS_CODE set, only people who know the code can install the addon or fetch its streams. With no access code configured, any value works (e.g. /stremio/public/manifest.json) and the server is open — set an ACCESS_CODE on public hosts.

    Why is my torrent stuck on “Connecting…”?

    On the Server engine, no peers means the torrent has no seeders. In the Browser P2P engine, browsers can only talk to WebRTC (WebTorrent) peers — classic BitTorrent clients are unreachable from a web page. The Server engine works with any torrent that has seeders.

    Which formats can I play?

    With the Server engine, essentially all of them: MP4, WebM, MKV, AVI, WMV, FLV, MOV, MPEG/TS — and audio like MP3, FLAC, OGG, WAV, AAC and Opus. If your browser can't decode a file natively (HEVC/H.265, DivX, AC3/DTS audio…) it is converted to H.264/AAC on the fly. The Browser P2P engine is limited to whatever your browser plays natively.

    Can I seek while watching?

    Yes for files your browser plays natively — they're served with HTTP range requests (in Stremio too). Converted streams can't seek while converting (inherent to progressive fragmented MP4).

    Is it legal?

    This tool is just a client, like any torrent app. Only stream content you have the right to access — public-domain, Creative Commons, or your own files.

    Do you store my files?

    Server-side data lives in a temp directory and is deleted when the torrent goes idle (default 20 minutes) or the server restarts. Nothing is retained between sessions.
